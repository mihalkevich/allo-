# 17. План outreach и партнёрские рассылки

Два канала набора гостей: (1) прямой outreach по своей базе `companies-base.csv`,
(2) рассылки партнёров по их базам корпоративных клиентов.

## Воронка и цель

Цель — 100–150 гостей на каждый день. На бесплатном B2B-событии no-show
30–50%, поэтому:

| Этап | Цель (на день) |
|------|----------------|
| Охват (приглашения отправлены) | 1500–2500 контактов |
| Регистрации | 220–300 |
| Подтвердили после обзвона | 160–200 |
| Пришли | 100–150 |

Набирать регистраций в **1.5–2×** от целевой явки.

## Канал 1 — прямой outreach по базе

База: `companies-base.csv` (215 компаний). На компанию — 1–3 ЛПР.
Последовательность касаний по каждому контакту:

| День | Касание | Канал |
|------|---------|-------|
| 19–21 мая | Save-the-date: коротко дата, тема, «детали скоро» | E-mail |
| 23–26 мая | Персональное приглашение + ссылка на регистрацию | E-mail |
| 27–30 мая | Звонок: подтвердить интерес, ответить на вопросы | Телефон |
| 2–5 июня | Догрев не ответившим: программа, спикер, подарок | E-mail / мессенджер |
| 9–10 июня | Звонок-подтверждение зарегистрированным, выбор дня | Телефон |
| 11–12 июня | Напоминание утром в день события | SMS / мессенджер |

Тексты писем и звонков — `06`. Приоритет A в базе (банки, АЗС, HoReCa,
телеком, ритейл) — обзванивать первыми.

### Скрипт звонка (коротко)

```
1. Представление: «Нейросети», ИИ-вендор, 10 лет.
2. Повод: юбилейное мероприятие 11-12 июня, бесплатно, для топ-менеджеров.
3. Ценность: разбор реальных кейсов внедрения ИИ + подарок каждому.
4. Действие: подтвердить участие и день, отправить ссылку/добавить в список.
5. Если не ЛПР: спросить, кто отвечает за цифровизацию, взять контакт.
```

### KPI outreach

- Контактов обработано / день.
- Конверсия приглашение → регистрация.
- Конверсия регистрация → подтверждение.
- Стоимость регистрации (если платный канал).

## Канал 2 — партнёрские рассылки по чужим базам

Партнёр анонсирует событие своей базе корпоративных клиентов. Это даёт охват
ЛПР, которых нет в нашей базе, и доверие через рекомендацию партнёра.

### Типы партнёров с базами ЛПР

| Тип | Что есть у партнёра |
|-----|---------------------|
| Деловые СМИ и порталы | Подписчики-руководители, рассылки |
| Бизнес-клубы и сообщества | База участников — собственники и топы |
| Бизнес-школы и центры обучения | База студентов-руководителей и выпускников |
| Коворкинги и деловые пространства | Резиденты-предприниматели |
| Отраслевые ассоциации и союзы | Члены ассоциаций |
| Банки и B2B-сервисы | База корпоративных клиентов |
| Площадка мероприятия | Корпоративные клиенты площадки (см. `15`) |

### Оффер для партнёра (что даём в обмен на рассылку)

- Co-branding: логотип партнёра в материалах и со сцены.
- Пакет бесплатных мест для команды/клиентов партнёра.
- Упоминание партнёра ведущим и в пост-релизе.
- Доступ к материалам и записи мероприятия.
- Взаимный анонс: мы рекламируем партнёра своей аудитории.
- Для бизнес-школ — спецусловия на наши программы обучения.

### Питч партнёру (шаблон)

```
Тема: Партнёрство — мероприятие для топ-менеджеров 11-12 июня

Добрый день! АО «Нейросети» (ИИ-вендор, 10 лет) проводит деловое
мероприятие для руководителей: разбор реальных кейсов внедрения ИИ.
Даты: 11-12 июня, Минск, участие бесплатное.

Предлагаем партнёрство: вы анонсируете событие своей аудитории
руководителей — мы даём co-branding, пакет бесплатных мест, упоминание
со сцены и в публикациях, взаимный анонс.

Это полезный бесплатный контент для вашей базы и видимость для вас.
Готовы обсудить формат?
```

### Процесс работы с партнёрами

1. Спринт 0–1: PRT составляет список партнёров, отправляет питчи.
2. Спринт 1: договорённости, передача партнёрам готовых материалов
   (текст анонса, баннер, ссылка с UTM-меткой партнёра).
3. Спринт 2: партнёрская рассылка — волна 1.
4. Спринт 3: волна 2 (дожим) + напоминание.
5. Учёт: у каждого партнёра своя UTM-метка — считаем регистрации по партнёру.

> Партнёр рассылает по СВОЕЙ базе и со СВОИМИ согласиями. Мы передаём только
> материалы, не получаем их базу — это законно (см. `12`).

## Сводный план набора

| Источник | Ожидаемый вклад в регистрации |
|----------|-------------------------------|
| Прямой outreach по базе | основной объём |
| Партнёрские рассылки | расширение охвата на новых ЛПР |
| Реклама и ретаргет (`12`) | дожим тёплой аудитории |
| Партизанские каналы (`11`) | дополнительный органический охват |

Контроль воронки — еженедельно на гейтах спринтов (`14`).
