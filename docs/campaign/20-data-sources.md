# 20. Карта источников данных (рейтинги, топы, каталоги)

«Дата-сенсор» базы компаний. Вместо обхода 215 сайтов по одному — берём
готовые списки из рейтингов, топов, реестров и каталогов, где компании
уже собраны и отсегментированы.

## Логика в два этапа

| Этап | Что даёт | Источники |
|------|----------|-----------|
| 1. КОГО собирать | Списки компаний + сегментация + размер бизнеса | Рейтинги, топы, премии, ассоциации |
| 2. КАК связаться | Телефон, email, адрес, УНП | Каталоги, реестры, парсер по сайтам (`parser/`) |

Рейтинги дают перечень и приоритизацию; контакты добираются каталогами,
реестрами и парсером. Итог сводится в `companies-base.csv` без дублей.

## Рекомендованный воркфлоу сбора

1. **Список (этап 1).** Снять перечни с BIK Ratings, probusiness, Office Life,
   dev.by, ПВТ, БелТПП, победителей «Брэнд года». Свести в один список,
   убрать дубли, проставить отрасль и приоритет.
2. **Контакты (этап 2).** По списку добрать контакты из каталогов
   (b2b.by, belpartner.by), реестров (kartoteka.by API) и парсером
   `parser/contact_parser.py` по сайтам.
3. **Свод.** Влить в `companies-base.csv`, дедуплицировать по названию/УНП,
   проставить `Статус`.

## Как собирать технически

- Рейтинги и топы — у каждой страницы своя вёрстка, нужен парсер под
  конкретную страницу (списочный парсер, не путать с `contact_parser.py`,
  который работает по сайтам компаний).
- Каталоги — постраничный обход разделов; часто есть фильтр по отрасли.
- kartoteka.by — официальный API, самый надёжный путь.
- Из облачного контейнера Claude Code сбор не идёт (сеть закрыта) —
  запускать у себя (см. `parser/README.md`).

## Легальность

См. `12-phone-audience-ads.md` и `18-contact-collector-agent.md`.
Каталоги и реестры публикуют контакты уровня организации — это законно для
делового приглашения. Госреестры — официальный открытый источник. Не
собираем персональные данные физлиц и не используем контакты для рекламных
рассылок физлицам без согласия.
