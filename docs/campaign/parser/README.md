# Контакт-парсер базы компаний

Скрипт `contact_parser.py` дособирает публичные контакты организаций
(телефон, email, соцсети) с их официальных сайтов и дописывает в
`companies-base.csv`.

## Важно: где запускать

В облачном контейнере Claude Code исходящая сеть закрыта политикой
окружения — даже `example.com` отдаёт `403`. **Парсер там не отработает.**
Запускайте на своей машине или сервере с открытым интернетом.

Часть белорусских корпоративных сайтов закрыта WAF и блокирует
автоматические запросы. Что собрать не удалось — допроверяет менеджер
вручную (статус `не найден` / `частично`) или см. вариант с браузерным
движком ниже.

## Установка

```bash
cd docs/campaign/parser
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
# весь файл
python3 contact_parser.py --input ../companies-base.csv \
    --output ../companies-base-enriched.csv --delay 3

# только приоритет A, первые 20 компаний (пробный прогон)
python3 contact_parser.py --priority A --limit 20
```

Параметры:
- `--input` / `--output` — пути к CSV;
- `--delay` — пауза между компаниями, секунд (по умолчанию 3, не уменьшать);
- `--timeout` — таймаут запроса;
- `--limit` — обработать не больше N компаний;
- `--priority` — фильтр `A` или `B`.

Строки со статусом `собран` / `частично` пропускаются — повторно собранные
вручную данные (банки, АЗС, телеком) не перезатираются.

## Что на выходе

`companies-base-enriched.csv` — та же база плюс колонки `Источник` и
`Дата_сбора`. Статус каждой строки:
- `собран` — найдены телефон и email;
- `частично` — найдено не всё;
- `не найден` — данных нет, на ручной добор;
- `ошибка` — сайт недоступен/заблокировал запрос;
- `нет сайта` — не заполнен домен, сначала нужно найти сайт.

## Если сайты блокируют (много `ошибка`)

Замените функцию `fetch()` на загрузку через headless-браузер
(Playwright) — он проходит большинство WAF:

```bash
pip install playwright && playwright install chromium
```

Логика парсинга (`find_contact_links`, `extract_*`) остаётся без изменений —
меняется только способ получения HTML.

## Легальность

См. `../12-phone-audience-ads.md` и `../18-contact-collector-agent.md`.
Собираются только публичные контакты уровня организации; `robots.txt`
уважается; включён rate-limiting. Персональные данные физлиц из закрытых
разделов не собираются. Контакты используются для делового приглашения
организаций, не для рекламных рассылок физлицам без согласия.
