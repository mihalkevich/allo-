# 12. Реклама по номерам: МТС и Facebook

Как настроить рекламу с использованием телефонных номеров — **легально**.

## Главное правило

Загружать в рекламные системы можно **только свои номера, собранные с
согласием** владельца (ваша CRM, регистрации с лендинга, текущие клиенты,
подписчики). Купленные, спарсенные или «холодные» базы:
- нарушают условия Meta (Custom Audiences) — аккаунт блокируется;
- нарушают законодательство РБ о персональных данных и о рекламе.

Поэтому ниже — две легальные схемы: своя база для Facebook и таргет по базе
**оператора** для МТС.

---

## A. Facebook / Instagram — Custom Audiences

«Реклама по номерам» в Meta = **Custom Audience из списка клиентов**.

**Что можно:**
1. Собрать СВОЮ базу с согласием на маркетинг:
   - форма на лендинге `[САЙТ/ЛЕНДИНГ]` с галочкой согласия;
   - регистрации на мероприятие;
   - текущие клиенты и подписчики «Нейросети».
2. Загрузить эту базу в Meta Ads Manager → Audiences → Custom Audience →
   Customer list. Данные хешируются на стороне Meta.
3. На основе неё создать **Lookalike Audience** — Meta найдёт похожих на
   ваших ЛПР. Это и есть масштабирование «по номерам» на новую аудиторию.
4. Ретаргетинг показывать на тех, кто уже в базе и ещё не зарегистрировался.

**Без номеров вообще** — поставить **Meta Pixel** на лендинг и ретаргетить
посетителей сайта. Номера для этого не нужны.

**Что нельзя:** загружать чужие/купленные номера. Meta требует подтверждения,
что у вас есть право использовать данные. Нарушение → бан рекламного аккаунта.

---

## B. МТС (и другие операторы) — таргет по базе оператора

Оператор **не даёт загружать чужие номера**. Легальная модель: оператор сам
показывает рекламу/шлёт SMS по СВОЕЙ базе, по сегменту, который вы заказали —
у оператора есть согласия абонентов.

**Что заказывать у МТС:**
- таргетированная SMS-рассылка по сегменту «руководители / бизнес-аудитория,
  гео Минск, возраст 30–60»;
- мобильная медийная реклама в сервисах оператора по тому же сегменту.

Вы передаёте оператору **бриф на сегмент**, а не список номеров. Тексты SMS —
в файле `06`.

Аналогично — рекламные сервисы А1 и life:).

---

## C. Бриф для медиабайера / менеджера оператора

```
Мероприятие: День рождения АО «Нейросети», 10 лет
Даты: 11 июня (деловой день) и 12 июня (праздник), Минск
Цель: регистрации на лендинге [САЙТ/ЛЕНДИНГ]
Аудитория: топ-менеджеры, директора, собственники; гео — Минск (+облцентры)
Сегмент: руководящие должности / интерес к бизнесу и IT, возраст 30–60
Период: с [дата старта] по 12 июня, усиление за 7 дней до события
Каналы: Facebook/Instagram (Custom + Lookalike + ретаргет), таргет-SMS МТС,
        мобильная реклама оператора
UTM: размечать каждый канал [UTM]
KPI: стоимость регистрации, число регистраций ЛПР
```

## D. Чек-лист настройки

- [ ] Лендинг с формой и **галочкой согласия** на маркетинговые коммуникации.
- [ ] Meta Pixel на лендинге, настроены события (регистрация).
- [ ] Своя база экспортирована из CRM, только контакты с согласием.
- [ ] Custom Audience загружена, создан Lookalike.
- [ ] Ретаргет-аудитории: посетители лендинга, незавершённые регистрации.
- [ ] Бриф на сегмент отправлен менеджеру МТС / А1.
- [ ] UTM-метки на всех каналах, сверка стоимости лида.

## E. Чего не делать

- Не загружать в Facebook купленные/спарсенные базы.
- Не просить у оператора «чужие номера» — он их не даёт, это незаконно.
- Не слать SMS по базам без согласия и без отписки.
- Не использовать данные из директорий (`08`, `09`) как «базу для загрузки» —
  это контакты организаций для делового приглашения, а не согласия физлиц на
  рекламу.
