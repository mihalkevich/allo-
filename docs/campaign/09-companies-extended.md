# 09. Расширенная директория компаний РБ (по результатам веб-поиска)

## Как собран этот список

Компании ниже собраны **веб-поиском по открытым каталогам, отраслевым
рейтингам и спискам предприятий** — это реальные организации, не выдуманные.
Сайты указаны там, где есть уверенность; **все домены и контакты проверять на
месте** (см. правило в `08`).

**Честно про «1000».** Списка из 1000 именно крупных компаний РБ не существует:
крупного бизнеса — несколько сотен, дальше идёт средний. Здесь ~200
реальных названных компаний. Чтобы дойти до 1000+, не выдумывая, используйте
каталоги-агрегаторы из раздела в конце файла — там тысячи реальных карточек с
контактами, выгружаемых по отраслям и регионам.

## Как дойти до 1000 (методика)

1. Определите 8–12 приоритетных отраслей под оффер мероприятия.
2. По каждой откройте каталог из списка выше → выгрузите карточки в таблицу.
3. Фильтр по размеру (выручка, штат) и гео — оставляйте только целевых.
4. Дедупликация, проверка домена, занесение в реестр (шаблон строки — в `02`).
5. Контакт берёте со страницы «Контакты» сайта компании; в реестр — с датой
   проверки и источником.
6. Поддерживайте легальность: контакты уровня организации, согласие на
   рассылку, опция отписки (см. `README.md` и `08`).
