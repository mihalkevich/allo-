# 14. План-график мероприятия (спринт на 25 дней)

Старт: 17 мая 2026 (Вс). Событие: 11–12 июня 2026 (Чт–Пт).
До события **25 дней** — режим сжатого спринта. Обратное планирование.

## Роли в команде

| Код | Роль | Зона ответственности |
|-----|------|----------------------|
| PM | Руководитель проекта | Общий план, бюджет, статусы, риски |
| OUT | Лид по базе и outreach | Сбор контактов, приглашения, обзвон, регистрации |
| MKT | Маркетинг / digital | Лендинг, реклама, креативы, рассылки |
| VEN | Площадка и логистика | Площадка, AV, кейтеринг, подрядчики, монтаж |
| CNT | Контент и сцена | Программа, сценарий, спикеры, ведущий, подарок |
| PRT | Партнёрства | Партнёры с базами, co-promo, инфопартнёры |

Минимально — 3–4 человека с совмещением ролей. Критично закрыть PM, OUT, VEN.

## Спринт 0 — 17–18 мая: ключевые решения

| Задача | Роль |
|--------|------|
| Утвердить бюджетную рамку и смету (`19`) | PM |
| Шорт-лист площадок, разослать запросы (`15`) | VEN |
| Решение по спикеру: подтвердить или закрыть вопрос | CNT |
| ТЗ агента-сборщика контактов, запуск (`18`) | OUT |
| Определить состав подарка «ИИ бизнес-аналитик» | CNT |
| Список партнёров с базами, заготовка оффера (`17`) | PRT |

**Гейт спринта 0:** бюджет утверждён, площадки запрошены, агент запущен.

## Спринт 1 — 19–25 мая: фундамент

| Задача | Роль |
|--------|------|
| Площадка выбрана и забронирована, договор, предоплата | VEN |
| Лендинг + форма регистрации с согласием — онлайн | MKT |
| База: первый прогон агента, ~215 компаний с контактами | OUT |
| Save-the-date рассылка по готовой части базы | OUT/MKT |
| Партнёрские договорённости, передача анонса партнёрам | PRT |
| Креативы: афиша, посты, баннеры (`04`, `05`) | MKT |
| Подрядчики: запросы КП — кейтеринг, AV, фото/видео | VEN |

**Гейт спринта 1:** площадка забронирована, регистрация открыта, база собрана.

## Спринт 2 — 26 мая – 1 июня: активный набор

| Задача | Роль |
|--------|------|
| Активный outreach: персональные приглашения + обзвон | OUT |
| Запуск рекламы: таргет, ретаргет (`12`) | MKT |
| Партнёрские рассылки по базам партнёров — волна 1 | PRT |
| Программа двух дней финализирована (`16`) | CNT |
| Спикер и ведущий/стендапер подтверждены договором | CNT |
| Подрядчики законтрактованы, кейтеринг-меню утверждено | VEN |
| Контроль воронки регистраций vs план | PM |

**Гейт спринта 2:** регистраций ≥ 60% от цели, программа и подрядчики закрыты.

## Спринт 3 — 2–8 июня: дожим

| Задача | Роль |
|--------|------|
| Дожим регистраций, обзвон «тёплых», волна 2 партнёров | OUT/PRT |
| Подтверждение гостей (звонок/сообщение), уточнение дня | OUT |
| Печать полиграфии: бейджи, программа, навигация | VEN |
| Подарки готовы и протестированы | CNT |
| Финальный run-of-show, брифинг команды и подрядчиков | PM/CNT |
| Репетиция сцены и техники | CNT/VEN |

**Гейт спринта 3:** регистраций ≥ 100% цели с учётом no-show, полиграфия готова.

## Финал — 9–12 июня

| Дата | Задача |
|------|--------|
| 9–10 июня | Финальные подтверждения, листы регистрации по дням, монтаж |
| 11 июня (Чт) | День 1 — деловая программа, мастер-класс |
| 12 июня (Пт) | День 2 — День рождения «Кайфануть», бизнес-стендап |

## После события — 13–20 июня

| Задача | Роль |
|--------|------|
| Лиды из листов регистрации → CRM, сегментация | OUT |
| Follow-up: благодарность + материалы + оффер | MKT |
| Апсейл: обучение, внедрение, бизнес-завтраки | OUT |
| Пост-релиз и контент с события | MKT/PRT |
| Разбор результатов vs KPI | PM |

## Ключевые риски

| Риск | Митигация |
|------|-----------|
| 25 дней — мало для набора ЛПР | Партнёрские рассылки + агент-сборщик с первого дня |
| Площадка на даты занята | Запросить 4–5 вариантов в спринт 0 |
| No-show на бесплатном событии (30–50%) | Набирать регистраций в 1.5–2× от цели, обзвон-подтверждение |
| Спикер не подтверждён | Промо без имени до договора; есть программа и без него |
| База собирается медленно | Агент + параллельно ручной сбор по приоритетным секторам |
