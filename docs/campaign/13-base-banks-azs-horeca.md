# 13. Приоритетные секторы: банки, АЗС, HoReCa

Детальная проработка трёх приоритетных секторов. Контакты брать из
первоисточников (см. `08`): сайт → «Контакты», футер → соцсети.

---

## Банки (полный сектор)

По данным Нацбанка, на конец 2025 г. в Беларуси действует **21 банк**. Сектор
небольшой и конечный — можно охватить целиком.

**Системно значимые, группа I:** Беларусбанк · Белагропромбанк · Приорбанк ·
Альфа-Банк.
**Системно значимые, группа II:** Сбер Банк · Белгазпромбанк · Банк БелВЭБ ·
МТБанк · Банк ВТБ (Беларусь) · Белорусский народный банк (БНБ) · Белинвестбанк.
**Прочие действующие:** Банк Дабрабыт · Паритетбанк · Технобанк · Банк РРБ ·
БТА Банк · Цептер Банк · БСБ Банк · Статусбанк и др.

Полный актуальный перечень всех 21 — на сайте Нацбанка `nbrb.by` и
справочниках `bankchart.by`, `banki24.by`, `belarus-inform.by`.

Целевые роли: Председатель правления, зам. по цифровой трансформации, директор
по IT, по рознице, по клиентскому сервису, руководитель антифрода, HR-директор.
Каналы: пресс-служба, форма «Партнёрам», корпоративные `pr@`/`marketing@`.

## АЗС — топливные сети (полный сектор)

Рынок концентрированный — крупных сетей немного, охватываются полностью.

| Сеть | Оператор | Масштаб |
|------|----------|---------|
| Белоруснефть (АЗС «Беларуснефть») | ПО «Белоруснефть» | ~574 АЗС — лидер рынка |
| Лукойл | ИООО «Лукойл Белоруссия» | ~84 АЗС |
| Газпромнефть | ИООО «Газпромнефть-Белнефтепродукт» | ~50 АЗС |
| А-100 | ОДО «Астотрейдинг» | ~36 АЗС |
| Роснефть / Славнефть | «РН-Запад» | ~33 АЗС |
| Татнефть | ИООО «Татбелнефтепродукт» | ~18 АЗС |
| МНПЗ Плюс | региональная сеть | ~3 АЗС (Мозырь) |

Целевые роли: коммерческий директор, директор по рознице, директор по IT/
цифровизации, директор по маркетингу и лояльности.
Каналы: корпоративные сайты сетей, пресс-службы, отделы маркетинга.
Релевантность ИИ: программы лояльности, прогноз спроса, клиентский сервис,
автоматизация документооборота.

## HoReCa — сети общепита

Сектор фрагментирован, крупных сетевых игроков — десятки. Ключевые операторы:

- **«Бел Фуд Сервис»** — крупнейший сетевой оператор (~54 ресторана).
- **«КреативФудС-Восток»** — ~29 ресторанов.
- **Cofix** (оператор «Урбан Снэки») — сеть кофеен.
- **«Varka»** — ~66 кофеен + кофейные автоматы.
- **«Хотфикс»** — оператор сетевого бренда общепита.
- Крупные рестораны и сети Минска — каталог `belretail.by/retailcategories/
  kafe-restoranyi` и портал `restorator.by`.

Целевые роли: собственник, операционный директор, директор сети, директор по
маркетингу, IT/digital-директор.
Каналы: сайты сетей, соцсети брендов (HoReCa активна в Instagram/Telegram),
отраслевой портал restorator.by, выставка HoReCa.
Релевантность ИИ: прогноз загрузки, автоматизация заказов и поддержки,
управление меню и закупками, обработка отзывов.
