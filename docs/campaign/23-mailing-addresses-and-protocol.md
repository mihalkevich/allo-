# 23. Адреса, каналы рассылки и протокол получения ответов

Готовый «оперативный пакет» для рассылки приглашений по списку из
`22-invitation-list-and-letters.md`: куда отправлять, по какому каналу,
что юридически обязывает гос. сектор ответить и в какие сроки, как вести
follow-up, чтобы повысить долю подтверждений.

> **TL;DR.**
> 1. Гос. сектор — Закон РБ от 18.07.2011 № 300-З + единая система
>    **обращения.бел** **обязывают** гос. органы и организации рассмотреть
>    письменное обращение юр. лица и дать **мотивированный письменный
>    ответ в 15 дней** (до 1 месяца с уведомлением о продлении). Это и есть
>    тот рычаг, при котором «обязательно ответят».
> 2. Для ПВТ и крупного частного бизнеса юридического обязательства нет —
>    там работает **личный канал + дисциплинированный follow-up**.
> 3. Ниже — верифицированные адреса и каналы по приоритетным
>    организациям, шаблон обращения по 300-З, протокол «звонки-напоминания»
>    и CRM-шаблон для трекинга.

## Часть 1. Юридическая основа — что заставит гос. сектор ответить

### 1.1. Закон №300-З «Об обращениях граждан и юридических лиц»

| Норма | Что значит для нас |
|-------|---------------------|
| Любое обращение юр. лица в гос. орган / гос. организацию подлежит обязательному рассмотрению | Письмо в канцелярию БелАЗа, БелЖД, Минсвязи и т.п. — не «приглашение, которое можно проигнорировать», а **обращение**, на которое адресат обязан ответить |
| Письменный ответ — **до 15 календарных дней** | Если не упомянуть нужду в проверке — срок 15 дней с момента регистрации |
| Сложные обращения — **до 1 месяца** с обязательным уведомлением | Срок продлевается только с письменным уведомлением заявителя |
| Ответ должен быть **мотивированным и обоснованным**, со ссылкой на нормы законодательства | Отказ должен быть аргументирован — не «нет», а «нет, потому что...» |
| Электронные обращения юр. лиц в гос. структуры подаются через единую систему **https://обращения.бел** (Закон в редакции, действующей с 02.01.2023) | Это **главный электронный канал** — регистрируется автоматически, статус отслеживается |

### 1.2. Обязательные реквизиты обращения юр. лица

- Полное наименование юр. лица-заявителя.
- Место нахождения (юр. адрес) заявителя.
- ФИО уполномоченного лица, имеющего право подписи (директор / по
  доверенности).
- Существо обращения (формулировка: «Просим рассмотреть возможность...»).
- На бумаге — собственноручная подпись + печать.

> Если хоть один реквизит отсутствует, адресат **вправе оставить обращение
> без рассмотрения** — это самая частая причина «тишины». Проверять чек-листом
> перед отправкой каждого письма.

## Часть 2. Каналы отправки — что использовать

Для гос. сектора рекомендуем **дублирующую отправку**: бумажный заказным +
электронная регистрация через обращения.бел. Так выше вероятность регистрации
и проще ссылаться на сроки.

| Канал | Когда применять | Доказательство получения |
|-------|------------------|---------------------------|
| **обращения.бел** — единая государственная система электронных обращений | Все гос. органы и гос. организации, кроме случаев, когда нужна именно «бумага на бланке за подписью» | Автоматическая регистрация + статус в личном кабинете |
| **Заказное письмо с уведомлением о вручении** (Белпочта, форма 117) | Все гос. предприятия + банки + министерства — для солидности и юр. фиксации | Бумажное уведомление о вручении с подписью получателя |
| **Прямой email канцелярии** | Когда канцелярия публикует email и принимает обращения именно так (БелАЗ — `office@belaz.minsk.by`, Беларуськалий — `belaruskali.office@kali.by` и т.д.) | Скан подписанного обращения с печатью + ответный email-регистрация |
| **Веб-форма обращений на сайте** | У некоторых организаций — собственная форма (Беларусбанк, БелЖД редиректят на обращения.бел) | Авторегистрационный номер от формы |
| **Личное вручение через приёмную** | VIP-адресаты (министры, председатели правлений) — через помощника/секретариат | Расписка на копии письма с печатью канцелярии |
| **Личный email / LinkedIn / мессенджер** | ПВТ-собственники, частный бизнес — только этот канал | Открытие / ответное письмо |

### 4.2. Рабочая схема outreach по ПВТ

1. **Тёплая интро через общего знакомого** (внутри ИТ-сообщества — узкий круг, цепочка из 1–2 рукопожатий).
2. **LinkedIn — короткое личное сообщение** (1–2 фразы + ссылка на программу).
3. **Корп. email с пометкой «Лично [имя]»** — пересылается ассистенту, доходит.
4. **Telegram-конференции и закрытые чаты** ИТ-сообщества (Belhard ИТ-клуб, dev.by-комьюнити) — для повторного «касания».
5. **Через инвесторов** (VP Capital, Palta) — если у организатора есть связи.

## Часть 7. Follow-up протокол — как доводить до подтверждения

Один контакт — это не рассылка, это начало работы. Протокол:

| День | Действие | Зачем |
|------|----------|-------|
| **T+0** | Отправка: заказным + дубль в обращения.бел / на email канцелярии | Запуск 15-дневного юр. срока для гос. сектора |
| **T+2** | Письмо ассистенту первого лица с короткой пометкой: «Отправили официально, прошу обратить внимание ***[И. О.]***» | Личное «оживление» |
| **T+3** | Звонок в канцелярию: подтвердить регистрацию, получить входящий номер | Без вх. номера письмо «потерялось» — нужен трекинг |
| **T+5** | Звонок секретарю / помощнику первого лица: подтвердить, что обращение лежит на рассмотрении | Поднимаем «над пачкой» |
| **T+7** | Личный звонок профильному заму (по цифровизации / ИТ / стратегии) | ЛПР по теме часто решает быстрее, чем первое лицо |
| **T+10** | Повторное письмо (email): «Уважаемый ***[И. О.]***, напоминаем по нашему обращению № *** от ***. Можем обсудить деталями по тел.» | Тёплое напоминание |
| **T+12** | Если контакт с помощником — точечная договорённость о слоте обсуждения | Конверсия в «да/нет» |
| **T+15** | Юридический срок ответа по 300-З истекает | Если ответа нет — основание для жалобы или личного контакта с приёмной |
| **T+18** | Если тишина: повторное обращение с указанием срока истёкшего ответа | Поднимает приоритет рассмотрения |
| **T+25** | Жалоба в вышестоящий орган (для гос. предприятий — отраслевой министр; для министерств — Совмин; для банков — Нацбанк) | Крайняя мера, использовать аккуратно — не «сжигать мост» |

### Распределение усилий

- **Базовый объём по каждой строке** — 3 касания (T+0 отправка, T+3 звонок,
  T+10 напоминание).
- **Приоритетный объём** (топ-30 строк, особо желанные гости) — все 7 касаний
  с персональной работой ассистента / профильного заместителя.
- **VIP-блок** (министры, СЕО банков, собственники крупного бизнеса) — у
  каждого личный «куратор» в команде проекта, ежедневный статус.

## Часть 9. Что сделать ДО первой отправки

1. **Сверить актуальные ФИО первых лиц** — пройти по всем строкам, открыть
   раздел «Руководство» на каждом сайте, обновить колонку «Руководитель».
2. **Зарегистрировать организатора в обращения.бел** (один раз) — заполнить
   данные юр. лица, подключить ЭЦП. Дальше — все электронные обращения
   подаются за минуты.
3. **Согласовать с юр. службой формулировку про курс А. Г. Лукашенко** —
   взять актуальную цитату/отсылку из president.gov.by или БелТА на момент
   рассылки.
4. **Подготовить пакет приложений** (программа + информация о компании) —
   один общий + 5 отраслевых модификаций (промышленность / энергетика /
   банки / ИТ / госорганы).
5. **Завести CRM** (см. Часть 8), назначить ответственных.
6. **Бланк и печать** — все письма треков A–C идут на бланке, с подписью и
   печатью.
