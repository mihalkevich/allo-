# **App Name**: Allo Services

## Core Features:

- Core UI/UX Layout: Display a clean, white interface with a prominent 'Allo' logo, language selection (RU/EN), and service toggle (SMS/eSIM).
- User Authentication: Implement phone number registration and login via Firebase Authentication, with input validation.
- SMS Interface: SMS tab: present available numbers for lease (flag, country, price, 'Lease' button), 'My Numbers' section (with 'Renew' button and comment field), and SMS history for each number.
- eSIM Interface: eSIM tab: display countries and plans for sale with relevant info; post-purchase, display the active subscription with data remaining and a QR code.
- Dashboards: Render analytics dashboards showing the status of SMS rentals, history, and the expiration of eSIM packages and traffic remaining, using Material Design.

## Style Guidelines:

- Primary color: Blue (#007BFF) for interactive elements to provide a modern, clean feel.
- Background color: White (#FFFFFF) for a bright and clean aesthetic.
- Secondary color: Light Gray (#F8F9FA) for subtle contrast and highlighting sections.
- Text color: Dark Gray (#343A40) for readability against the white background.
- Body and headline font: 'Roboto' (sans-serif) for a modern and easily readable text.
- Maintain a clean and spacious layout using a 12pt grid system. Use a 20px minimum padding between blocks, 32px between cards, ensuring a well-spaced and airy feel.
- Use simple and clear line icons for easy recognition and a light aesthetic.
- Implement subtle fade-in animations for content loading and transitions to provide a smooth user experience.
